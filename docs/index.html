位置感知解析器组合子库

基础组合
let p = @astrolabe.char('a')
match p.parse("abc") {
  Ok(c) => println("parsed: \{c}")
  Err(e) => println(e.format())
}

let greeting = @astrolabe.map(
  @astrolabe.string("hello"),
  fn(s) { s.length() },
)
三入口与错误
parser.parse(input)        // 允许尾部
parser.parse_prefix(input) // (值, 剩余输入) — 新增
parser.parse_full(input)   // 必须全消费

match parser.parse_full(input) {
  Err(e) => {
    println(e.pos().to_string())      // 1:3@2 — 新增
    println(e.expected_joined())      // "digit | letter" — 新增
    println(e.format_with_input(input))
  }
  Ok(v) => println(v)
}
回溯控制
let backtracking = @astrolabe.alt(
  @astrolabe.string("ab"),
  @astrolabe.string("ac"),
)
let committed = @astrolabe.alt(
  @astrolabe.commit(@astrolabe.string("ab")),
  @astrolabe.string("ac"),
)
// 输入 "ac"：backtracking 成功，committed 失败（承诺后不回退）

Under the hood

这是怎么在浏览器里跑的？

  1. 1

    playground/ 是根模块的 foreign_library 包，用 #export_name 导出 11 个非 raise 包装函数（错误折叠为 {"ok":false}）。

  2. 2

    moon build --target js --release playground 生成一份 JS；同一份源码也可构建为 wasm-gc / native。

  3. 3

    页面直接 import 并调用：解析、三入口、错误上下文、commit/alt、位置追踪全部本地完成。

  4. 4

    语义由 239×4 测试、10 点变异矩阵与 7 条 Z3 性质守护；check_pages.mjs 验证导出与语义。
